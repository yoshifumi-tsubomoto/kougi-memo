# 3. 講義1回分の流れ

[← 目次](README.md)

## 1. 講義を作る

「＋ 新しい講義」を押し、タイトル・講師・日付・会場を入れます。入れた内容は自動で保存されます。

## 2. セッションを始める

講義が始まったら「● セッション開始」を押します。はじめての時は、マイクの使用を許可してください。

- **左**に、リアルタイムの文字起こしが時刻付きで流れます
- 画面の右上で、「音声認識」と「録音」が動いているかを確かめられます
- 記録中は、パソコンの画面が消えないようにしています。パソコンは電源につないでください

## 3. メモと写真を残す

右の欄で、種類を選んでから書き、Enter で追加します（Shift+Enter で改行）。

| 種類 | 使いどころ | 切り替え |
|---|---|---|
| メモ | ふつうの気づき | Alt+1 |
| 要点 | 大事なところ。マーカーで目立ちます | Alt+2 |
| 質問 | あとで聞きたいこと | Alt+3 |
| TODO | 自分がやること | Alt+4 |
| 引用 | 講師の言葉そのまま | Alt+5 |

写真は「🖼」のボタンのほか、**貼り付け（Ctrl+V）**や**ドラッグ**でも追加できます。スライドの画面写真などに便利です。

## スマホと連携する（講義中にスマホの写真を見る）

1. 画面の右上の「📱 スマホ」を押すと、QRコードが出ます
2. スマホのカメラで読み取ると、スマホに「講義メモ・スマホから送る」のページが開きます。「PCとつながっています」と出たら準備完了です
3. 「📷 写真を撮って送る」で撮ると、数秒でパソコンの「メモ・写真」に届きます（📱 の印が付きます）。メモや質問も送れます

- 写真は、スマホからパソコンへ暗号化して直接届きます。つなぐ手続きには無料の仲介サービス（PeerJS）を使います。会場のネットワークによっては、その中継を通りますが、中身は見えません
- このページで撮った写真は、スマホには残りません。残したいときは、ふつうのカメラで撮ってから「アルバムから選んで送る」を使います
- QRコードは、ほかの人に見せないでください。心配なときは「QRコードを作り直す」を押すと、前のQRコードではつながらなくなります

**つながらないときは**、ふつうのカメラで撮っておき、講義のあとで写真をパソコンに移して「🖼」から選びます。写真に記録された撮影時刻を読んで、その時刻の位置に並べます。

## 画面を広く使う

- 右上の「⤢ 広く表示」を押すと、講義の情報（タイトル・講師など）や状態の文字が隠れ、タブとセッションの操作が上の帯に1行でまとまります。メモの入力欄も大きくなります。もう一度押すと元に戻ります（右上のボタンは記号だけになります。マウスを乗せると名前が出ます）
- 文字起こしの欄の「◀ たたむ」を押すと、文字起こしが細い帯になり、メモと写真を横いっぱいに使えます。帯を押すと元に戻ります
- メモの入力欄は、右下のつまみで狭くも広くもできます。変えた高さは覚えています
- 写真は左に小さく並び、そのあとのメモが写真の横に回り込みます。大きさはメモ欄の上の「写真」で選べます（小・中・大・幅いっぱい）。欄の幅が足りないときは、写真の下に文字が続きます。写真を押すと大きく見られます
- 文字起こしとメモは、新しいものが来ると自動で下までスクロールします（それぞれの「自動スクロール」で止められます）
- どちらも、開き直しても覚えています
- 拡大した写真は、写真を押すか、「×」か、Esc キーで閉じます

## オンラインの講義（Zoom・Teams・YouTube など）

**音を取り込む**：「⚙ 設定」→「音声の入力」で選びます。

- **ステレオミキサーなど「PCの音」が入る機器**があれば、それを選びます。リアルタイム文字起こしにも使うには、Chrome のマイクの設定（アドレスバー左のマーク →「サイトの設定」→「マイク」）でも同じ機器を選んでください
- そうした機器がないときは「**画面共有の音声**」を選び、メモ欄の「🖥 画面を撮る」で共有するときに「タブの音声も共有する」をオンにします。録音には使えますが、リアルタイム文字起こしはブラウザによっては使えません（そのときは録音から清書します）

**スライドを撮る**：メモ欄の下の「🖥 画面を撮る」を押し、Zoom などのタブ（または画面）を共有します。

1. 最初に、撮る範囲をドラッグで囲みます（「画面全体を撮る」も選べます）
2. 「📷 撮る」（または Alt+S）で、その範囲がメモに写真として入ります（🖥 の印が付きます）
3. 「スライドが変わったら自動で撮る」をオンにすると、範囲の画面が大きく変わって止まったときに自動で撮ります
4. 範囲は覚えておき、次に共有したときも同じ範囲を使います。「範囲を決める」で変えられます

## 4. 区切る・終わる

- 休憩や話題の切れ目で「⏭ 次のセッションへ」を押すと、セッションが分かれます。録音も、そこで区切られます
- 講義が終わったら「■ 終了」を押します。書き出しの案内が出ます

## 途中でページが閉じてしまったら

もう一度開くと、記録はそのまま残っています（録音は最後の1分ほどが欠けることがあります）。「● 記録を再開」を押すと続けられます。
