# 8. 清書する（録音を、ていねいに文字にし直す）

[← 目次](README.md)

リアルタイムの文字起こしは、速さを優先するので誤りが出ます。セッションが終わったあとで、録音をもう一度ていねいに文字にし直すのが「清書」です。

## 清書の方法を選ぶ

「⚙ 設定」→「清書（高精度の文字起こし）の方法」で選びます。

| 方法 | 向いている人 | 音声の行き先 |
|---|---|---|
| ② OpenAI で清書する | 速く、正確にしたい人（料金がかかる） | OpenAI |
| ③ Gemini で清書する | Google のサービスを使いたい人（**有料の枠で**） | Google |

- ②③ を選ぶと、APIキーを入れる欄が出ます。キーは、そのブラウザの中にだけ保存します。**共用のPCでは入れないでください。**
- ②③ は、録音の音声を外のサービスに送ります。学校や職場の決まりを確かめてから使ってください。

### APIキーの取り方

- **OpenAI**：https://platform.openai.com/ でアカウントを作り、「API keys」でキーを作ります。使うには、料金の支払いの設定が必要です。
- **Gemini**：https://aistudio.google.com/ で「Get API key」からキーを作ります。**かならず支払いの設定（有料の枠）をしてから使ってください。** 無料の枠では、送った音声や文章が Google の AI の学習に使われることがあり、講義の録音を送るのには向きません。

## 清書する

1. 「まとめ・出力」を開きます。
2. 終わったセッションの「**✨ 清書する**」を押します。
3. 進み具合と、あと何分くらいかが出ます。終わるまで、このページを閉じないでください。「やめる」で途中でやめられます。
4. 終わると「✓ 清書済み」と出ます。文字起こしの文字数の横が「（清書）」になり、要約用のコピーや書き出しでは、清書した文字が使われます。

清書をやり直すときは、「清書をやり直す」を押します。前の清書は、新しい清書に入れかわります。

## 要約を作る

「⚙ 設定」→「**要約の方法**」で選びます。清書とは別に選べます（選んでいないときは、清書と同じサービスを使います）。

| 方法 | APIキー | ひとこと |
|---|---|---|
| コピーして、自分でAIに貼る | いらない | 「要約用にコピー」で文章をコピーし、学校の Gemini などに貼り付けます |
| OpenAI で作る | OpenAI | 清書を OpenAI でしているなら、同じキーで作れます |
| Gemini で作る | Gemini（有料の枠） | 清書を Gemini でしているなら、同じキーで作れます |
| Claude で作る | Claude | 清書をしない人にも向いています。Haiku なら1時間ぶんで1円未満です |

OpenAI・Gemini・Claude を選ぶと、「まとめ・出力」の各セッションに「**✨ 要約を作る**」が出ます。押すと、そのセッションの文字起こし（清書があれば清書）とメモから、指定した文字数で要約を作り、下の欄に保存します。

- 欄にすでに要約があるときは、置きかえてよいかを聞きます。
- 要約に使うモデルは、「⚙ 設定」で変えられます（OpenAI は gpt-4o-mini、Claude は claude-haiku-5-5 が最初の設定です）。
- **Claude は、要約だけに使えます。** Claude は音声を受け付けないので、清書（録音の文字起こし）には使えません。
- Claude の APIキーは、Claude Console（https://platform.claude.com/ ）で作ります。使った分だけ払うしくみで、支払いの設定が必要です。初期設定では、送った内容は学習に使われません。

## かかる料金のめやす（1時間の録音）

| | 清書 | 要約 |
|---|---|---|
| OpenAI（whisper-1） | 約0.36ドル（50〜60円） | 1円未満（gpt-4o-mini） |
| OpenAI（gpt-4o-mini-transcribe） | 約0.18ドル（25〜30円） | 同上 |
| Gemini（2.5 Flash） | 約0.1〜0.15ドル（15〜25円） | 1円未満 |
| Claude（Haiku 5.5） | 使えません | 1円未満（約0.2円） |

料金は変わることがあります。くわしくは、OpenAI・Google の料金のページで確かめてください。

## 清書が済んだ録音を消す

録音は、4時間で約60MBの場所を取ります。清書が済んだら、「**清書が済んだ録音を消す**」で消せます。

- 消した録音は、元に戻せません。
- 清書した文字・リアルタイムの文字起こし・メモ・写真は残ります。
- 録音も残しておきたいときは、先に「フォルダに書き出し」で保存してください。
