# 2. 開く・アプリとして登録する

[← 目次](README.md)

## 開く

Chrome か Edge で、次の URL を開きます。ログインはいりません。

https://yoshifumi-tsubomoto.github.io/kougi-memo/

## アプリとして登録する（おすすめ）

画面の右上の「⬇ アプリとして入れる」（またはアドレスバーの右の端のボタン）を押すと、講義メモがアプリとして登録されます。パソコンにソフトを入れるわけではありません。

- ブラウザに記録を消されにくくなります
- ネットがないときも開けます
- スタートメニューやシェルフ（Chromebook）から、専用の窓で開けます

## 新しい版が出たとき

画面の上に「新しい版があります」と出ます。記録の途中で勝手に変わることはありません。区切りのよいところで「更新する」を押してください。記録中は更新できません。

## 同じ端末・同じブラウザで使う

記録は、**端末ごと・ブラウザごと**に別々です。別の端末で続けるときは、[5. データを守るために](05-data.md) のバックアップを使います。

**タブは1つで**使ってください。2つ開くと注意が出ます。
