# 1. はじめに（必要なもの）

[← 目次](README.md)

講義メモは、講義・研修・講演会・セミナーなど、長い話（4時間程度まで）をまるごと記録し、セッションごとにまとめるアプリです。

## 必要なもの

| もの | くわしく |
|---|---|
| パソコン | Windows・Mac・Chromebook。長い時間使うので、電源につなげるもの |
| ブラウザ | **Chrome か Edge**。リアルタイム文字起こしは、この2つでしか動きません |
| マイク | パソコンの内蔵マイクでも動きます。講師の声が直接届く位置にあるほど、文字起こしの精度が上がります |
| インターネット | リアルタイム文字起こしに必要です。つながらない間も、録音とメモは続きます |

## 記録する前に

- 講義を録音・文字起こしするときは、**講師や主催者の了解**を得てください
- 学校や職場で使うときは、そこの情報管理のきまりに従ってください
- リアルタイム文字起こしは、ブラウザの音声認識を使います。**話している音声は、Chrome なら Google、Edge なら Microsoft に送られます**。録音・メモ・写真は送られません
