# 講義メモ

**ブラウザで開くだけ。記録は、この端末から出ません。**

講義・研修・講演会・セミナーなど、長い話（4時間程度まで）をまるごと記録し、セッションごとにまとめるアプリです。

- **リアルタイム文字起こし**：話した言葉が、時刻付きで流れていきます。途中で止まっても自動で再開します
- **録音**：約10分ごとに区切って、ブラウザの中に保存します。1分ごとに書き込むので、PCが止まっても失うのは最大1分です
- **メモと写真**：「メモ・要点・質問・TODO・引用」に分けて書けます。写真は貼り付け（Ctrl+V）やドラッグでも追加できます
- **セッション**：休憩などで「次のセッションへ」を押して区切ります。時刻はすべて自動で記録されます
- **まとめ**：セッションごとに文字数を決めて「要約用にコピー」し、使ってよいAIに貼り付けて要約させます
- **出力**：Markdown、写真入りの印刷・PDF、フォルダへの書き出し（録音・写真も）、バックアップ

## 開く

（GitHub Pages で公開したら、ここに URL を書く）

- Chrome か Edge で開いてください。リアルタイム文字起こしは、この2つでしか動きません
- 一度開けば、ネットがなくても開けます（ブラウザにアプリをしまいます）
- 右上の「アプリとして入れる」を押すと、専用の窓で開け、記録もブラウザに消されにくくなります

## しくみ

```
GitHub（アプリのプログラムを配るだけ）
   ├─→ A先生のブラウザ：A先生の記録だけ
   └─→ B先生のブラウザ：B先生の記録だけ
```

- URL を開くと、アプリのプログラムだけが届き、**それぞれのブラウザの中で**動きます。ログインはいりません
- 文字起こし・メモ・写真・録音は、**開いている端末のブラウザの中だけ**に保存します

## 記録のデータについて

- このページの持ち主を含め、だれかのサーバーに記録を送ることはありません
- ただし、**リアルタイム文字起こしは Chrome（Edge）の音声認識を使うため、話している音声が Google（Microsoft）に送られます**。録音とメモは送られません
- 講義を録音・文字起こしするときは、講師や主催者の了解を得てください。学校で使うときは、学校の情報管理のきまりに従ってください

### ブラウザの中にあるもの（消えるとなくなるもの）

講義の情報、文字起こし、メモ、写真、録音（4時間で約60MB）、要約は、**その端末のそのブラウザの中だけ**にあります。サーバーにもほかの端末にもコピーはありません。

次のときに消えます。

- ブラウザで「閲覧履歴データの削除」→「Cookie と他のサイトデータ」を選んだとき、または `yoshifumi-tsubomoto.github.io` のデータを削除したとき。**同じ場所で動いているココデマルなどのデータも一緒に消えます**
- パソコンの空き容量が足りなくなり、ブラウザが自動で消したとき（「アプリとして入れる」と消されにくくなります。⚙ 設定で状態を確かめられます）
- アプリを削除するときに「データも削除」を選んだとき
- シークレットウィンドウで使い、窓を閉じたとき
- ログアウトや再起動のたびに初期化される共用PCで使ったとき

### 守り方

- 講義が終わったら、「まとめ・出力」から書き出します
  - **フォルダに書き出し**：文字起こし・メモ（Markdown）、写真、録音をパソコンのフォルダに保存します
  - **バックアップを書き出す**：講義メモに読み込み直せるファイルです。別の端末で続けるときにも使います（音声も含めるかを選べます）
- 書き出していない講義には、一覧で「●（未書き出し）」の印が付きます。書き出した後に変更すると、また印が付きます
- セッションを終了すると、書き出しの案内が出ます

## 長い時間つかうときは

- PCは電源につなぎ、スリープしない設定にしてください（記録中は画面が消えないようにしています）
- マイクは、講師の声が直接届く位置にあるほど精度が上がります
- タブは1つで使ってください

## 清書（高精度の文字起こし）

「⚙ 設定」で方法を選べるようにしていきます。

| | 方法 | 状態 |
|---|---|---|
| ① | 清書しない（リアルタイムの速報だけ） | ✅ 使えます |
| ② | このPCの中で清書する（音声を外部に送らない） | 🔜 次に作ります |
| ③ | OpenAI で清書する（自分のAPIキー） | 🔜 予定 |
| ④ | Gemini で清書する（自分のAPIキー） | 🔜 予定 |

## 開発

```
docs/            アプリ本体（GitHub Pages でこのフォルダを公開する）
  index.html
  style.css
  js/app.js      画面と動き
  js/store.js    保存（ブラウザの中の IndexedDB）
  sw.js          ネットがなくても開けるようにする仕組み
  manifest.webmanifest, icons/
tools/
  serve.mjs      手元で開くためのサーバー
  check.mjs      画面を自動で操作して、基本の流れを確かめる
legacy/gas/      最初に作った Google Apps Script 版（参考として残しているもの）
```

ビルドはいりません。`docs/` のファイルがそのまま配られます。

```bash
npm start
```

http://localhost:8080/ で開けます。

```bash
npm run check
```

講義の作成、メモ、録音の保存、再読み込み、Markdown出力、バックアップの往復を自動で確かめます（Playwright が必要）。音声認識は自動では確かめられないので、実機で確認します。

### 新しい版を出すとき

1. `docs/js/app.js` の `APP_VERSION` と、`docs/sw.js` の `VERSION` を同じ番号に上げる（**`sw.js` を変えないと、使っている人に新しい版が届きません**）
2. `npm run check` が通ることを確かめる
3. `main` に入れると、GitHub Pages に反映されます。使っている人の画面には「新しい版があります」と出て、本人が押したときに切り替わります
