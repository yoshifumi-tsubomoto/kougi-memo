講義メモ

講義・研修・講演会を、まるごと記録してセッションごとにまとめます。

  1. 「新しい講義」を作り、タイトルと講師を入れる
  2. 始まったら「セッション開始」。文字起こしと録音が自動で進みます
  3. 気づいたことはメモに。写真は貼り付け・ドラッグでも追加できます
  4. 終わったら「まとめ・出力」で、セッションごとに要約して書き出し

記録はこのブラウザの中だけに保存されます。インターネットに送られるのは、Chromeの音声認識が使う音声だけです。

    このアプリについて

    記録はこのブラウザの中（IndexedDB）に保存されます。別のPCやブラウザとは共有されません。ブラウザの「閲覧履歴データの削除」でサイトデータを消すと、記録も消えます。大事な記録は「まとめ・出力」からフォルダに書き出してください。

    スマホと連携

    準備しています…
    1. スマホのカメラでQRコードを読み、開いたページで写真を撮ります
    2. 撮った写真やメモが、数秒でこの画面の「メモ・写真」に届きます
    3. この画面を閉じても、つながったままです

    写真は、スマホからこのPCへ暗号化して直接届きます（つなぐ手続きには無料の仲介サービス PeerJS を使い、直接つながらないときはその中継を通ります。中継でも中身は見えません）。QRコードは、ほかの人に見せないでください。
